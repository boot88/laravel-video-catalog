# Video Catalog — видеокаталог на Laravel

Веб-каталог видео с категориями, страницей просмотра, полноэкранным режимом, комментариями, лайками и сортировкой по активности.

**Текущая версия:** каталог для просмотра предварительно подготовленных видеофайлов. Веб-загрузка пользователем, полноценный аккаунт автора и потоковое перекодирование в этой версии не представлены.

## Реализованные возможности

- Категории из базы данных и папок импорта.
- Пагинация и сортировка по просмотрам, комментариям и лайкам.
- Отдельная страница ролика и полноэкранный просмотр.
- Комментарии с проверкой текста и ограничением частоты по IP.
- Лайки с проверкой повторного действия в пределах сессии.
- Модель видео, миграции, демонстрационный сидер.
- Сервис формирования миниатюр через FFmpeg с резервными изображениями.

## Технологии

PHP 8.2+, Laravel 12, Eloquent, Blade, JavaScript, Vite, FFmpeg и GD.

## Подготовка локального окружения

```bash
git clone https://github.com/boot88/VideoHosting.git
cd VideoHosting
composer install
cp .env.example .env
php artisan key:generate
npm install
npm run build
```

Настройте отдельную локальную базу в `.env`. При выборе SQLite создайте файл `database/database.sqlite`.

```bash
php artisan migrate
php artisan storage:link
php artisan serve
```

Каталог открывается по адресу `http://127.0.0.1:8000`. Сами видео и миниатюры нужно подготовить отдельно: записи в базе не заменяют медиаданные.

## Особенности текущей реализации

- Сидер создаёт демонстрационные записи и ссылается на заранее подготовленные файлы. Он очищает таблицу видео, поэтому предназначен для отдельной демо-базы.
- Пути к FFmpeg и работа с путями в сервисе миниатюр ориентированы на Windows-окружение. Перед запуском генерации на другой ОС требуется адаптация.
- В репозитории есть несколько команд генерации миниатюр; их поведение нужно проверять для выбранного окружения.
- Отдельное доменное покрытие каталога и медиасценариев тестами пока требуется расширить.

Базовая команда тестов: `php artisan test`.
